# Veblock 0.24.0

- Подписки: если основной адрес не отвечает, серверы один раз загружаются с запасного адреса провайдера (`fallback-url`). Адрес подписки при этом не меняется.
- Подписки: после загрузки с запасного адреса приложение предлагает перейти на него насовсем; в строке подписки появляется подпись «Обновлено через запасной адрес».
- Подписки: после 404 и 410 или сбоя обоих адресов смена адреса больше не предлагается.
- Подписки: при смене адреса подписки запасной адрес прежнего провайдера забывается.
