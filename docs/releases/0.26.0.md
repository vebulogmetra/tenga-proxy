# Veblock 0.26.0

- Новое окно «Диагностика сети»: меню, `Ctrl+D` или кнопка на вкладке «Диагностика». Проверяет сеть, DNS, доступность сервисов и белые списки, показывает итог с рекомендациями, отчёт можно сохранить в файл: адресов в нём нет. Цели, пороги и формат отчёта те же, что в Android-версии.
- При подключении через TUN прямые проверки на Linux идут мимо туннеля и не мешают сеансу, а сервисы сравниваются ещё и через сервер.
- Если прямой путь проверить нельзя (включена блокировка трафика или у сети нет своего маршрута), прямые запросы не отправляются, и окно говорит об этом, а не о сбое сети.
- Windows: при подключении через TUN прямые проверки пока не выполняются, окно показывает их как недоступные.
- Проверяется только IPv4.
