# Veblock 0.21.0

- Windows: новый интерфейс на Qt в системном стиле Windows 10 и 11 вместо GTK.
- Windows: значок в трее, его меню и уведомления — системные.
- Windows: центральный кликабельный монолит управляет подключением; подпись объясняет текущее действие.
- Windows: карточка подключения и список серверов центрированы и ограничены по ширине; низкие окна используют компактную компоновку.
- Windows: активный и выбранный серверы различаются, переключение выполняется явно; диагностика открывается по запросу.
- Windows: прогресс проверки задержки отображается полосой в строке группы.
- Windows: светлая тема по умолчанию для новых настроек; сохранённый выбор темы сохраняется.
- Windows: выровнены кнопки и строки обслуживания, убраны дублирующие инструкции и пункт «О программе» из главного меню; раздел доступен в настройках.
- Linux: интерфейс и поведение без изменений.
