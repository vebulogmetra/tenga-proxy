# Veblock 0.29.0

- Замер задержки работает при активном TUN и при заблокированном трафике: пробы идут мимо туннеля через физический интерфейс и не задевают сеанс. Если обойти туннель нечем, приложение сообщает об этом.
- Linux: в режиме TUN маршрут по умолчанию больше не заменяется: в туннель ведут `0.0.0.0/1` и `128.0.0.0/1`. Маршруты сеанса старой версии снимаются при следующем запуске.
- Linux: новая компоновка окна, как на Windows: состояние с голубем и свечением слева, серверы и диагностика справа. Двухстрочные строки серверов, поиск и сортировка; настройки с разделами, подписки переехали в них.
- Windows: обновление приложения из «О программе» → «Обновить…»: установщик скачивается, сверяется и запускается, после установки Veblock открывается снова.
- deb-пакет зависит от `python3-gi-cairo`: без него новое окно не запускалось.
