# Veblock 0.29.2

- Windows: ускорены подключение и отключение TUN. Снимок сети читается через Windows API, ядро ожидается до фактической готовности, а настройка DNS использует постоянный сеанс DnsClient.
- Windows: настройка сопутствующего VPN и список «Через VPN» убраны из интерфейса. Возможность остаётся на Linux; сохранённые Linux-настройки на Windows не применяются и сохраняются при редактировании.
- Windows: исправлен запуск сборки при попадании сторонней ICU DLL в пакет; обновление удаляет конфликтующую библиотеку.
- Ошибки запуска графического интерфейса записываются в журнал.
- В строке сервера кнопка проверки задержки заменена иконкой спидометра; надпись «Подключён» выровнена по центру рамки.
