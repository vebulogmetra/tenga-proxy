# Veblock 0.22.0

- Linux: во время подключения кнопка показывает «Подключение…» и недоступна — ложная «Отменить», которая ничего не прерывала, убрана из окна и меню трея.
- Linux: ошибка подключения остаётся на карточке статуса до новой попытки; кнопка предлагает «Повторить».
- Linux: без подключения карточка называет сервер, к которому подключит кнопка: выбранный в списке или последний использованный.
- Linux: подключённый профиль помечен в списке надписью «Подключён», а не только цветом.
- Linux: если при активном соединении выбран другой профиль, карточка предлагает явное «Переключить на «…»»; выделение само соединение не меняет.
- Linux: «Подключено» означает запущенную сессию, результат проверки соединения показан отдельной строкой.
- Linux: страница настроек «О программе» переименована в «Версия»; «О программе» осталось в главном меню.
- Windows: центральный кликабельный монолит управляет подключением; подпись объясняет текущее действие.
- Windows: карточка подключения и список серверов центрированы и ограничены по ширине; низкие окна используют компактную компоновку.
- Windows: активный и выбранный серверы различаются, переключение выполняется явно; диагностика открывается по запросу.
- Windows: прогресс проверки задержки отображается полосой в строке группы.
- Windows: светлая тема по умолчанию для новых настроек; сохранённый выбор темы сохраняется.
- Windows: выровнены кнопки и строки обслуживания, убраны дублирующие инструкции и пункт «О программе» из главного меню; раздел доступен в настройках.
- Windows: во время подключения меню трея показывает «Подключение…» вместо неработающего «Отменить».
