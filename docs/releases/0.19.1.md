# Veblock 0.19.1 — Windows

Исправительный выпуск для Windows.

- Исправлено отображение флагов стран в именах серверов в главном окне:
  используются готовые растровые изображения, как в Windows-трее.
- Устранено ожидание таймаута потока журнала при остановке ядра в службе.
- Устранены повторные запросы сетевых данных через PowerShell сразу после
  медленного сбора: срок кэша теперь отсчитывается от завершения запроса.

Для обновления используйте установщик 0.19.1: приложение и Windows-служба
должны иметь одинаковую версию. Обновление исходников не обновляет установленную
службу.

Функциональных изменений для Linux в этом выпуске нет.
