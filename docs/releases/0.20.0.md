# Veblock 0.20.0

- Окно импорта маршрутизации показывает имя профиля, изменения по каждому списку и куда пойдёт остальной трафик.
- Маршрутизацию до импорта можно вернуть: кнопкой в уведомлении или в «Настройки → О приложении → Обслуживание».
- Правила `full:` и `domain:` с заглавными буквами и кириллицей теперь срабатывают.
- Импорт больше не стирает VPN-список у старых установок.
