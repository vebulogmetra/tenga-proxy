# Veblock 0.28.0

- Новая страница настроек «Маршрутизация»: общие правила (режим, приоритет групп, готовые правила и списки) для всех серверов. Строка «Маршрутизация до импорта» → «Вернуть» переехала сюда из «О программе».
- У сервера можно включить «Свои правила маршрутизации» в «VPN и маршруты…»: тогда общие правила на него не действуют. На странице мониторинга строка «Правила» показывает, какие применены.
- Набор маршрутов из заголовка `routing` подписки (Happ, Veblock) предлагается после обновления в окне импорта и применяется только по кнопке «Импортировать». Один и тот же набор повторно не предлагается; `routing/off` предлагает вернуть стандартные списки.
