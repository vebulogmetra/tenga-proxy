# Veblock: общий дизайн Linux и Windows

Статус: действующий документ. Два тулкита, логотипы, вкладки на Linux, значок трея и
термин «Сервер» утверждены и реализованы; пункты с пометкой «предложено» реализованы и ждут
подтверждения. База: `7e6e23a`. Связанный документ: `2026-10-29-windows-ux-design.md`.

## Принцип

Один дизайн, две реализации: GTK 4 + libadwaita на Linux, Qt (PySide6) на Windows.
Пользователь видит один продукт: те же состояния, слова и действия.

**Намеренных отличий в дизайне два: логотип и навигация.** Всё остальное расхождение
считается долгом, пока не описано в разделе «Что определяет платформа».

Новая функция с интерфейсом считается готовой, когда сделана в обоих тулкитах
или когда отсрочка для одного из них записана в раздел «Расхождения».

## Намеренное отличие: логотип

| | Linux (GTK) | Windows (Qt) |
| --- | --- | --- |
| Логотип | Голубь со щитом | Монолит |
| Карточка статуса | `assets/logo-inner-256.png` | `assets/icons/win/monolith.svg` |
| Значок приложения | `assets/theme/hicolor/…/tenga-proxy.png` | `assets/tenga-proxy.ico` |
| «О программе» | `assets/theme/hicolor/…/tenga-proxy.png` | `assets/icons/win/monolith.svg` |
| Трей | Символьное кольцо `assets/icons/tenga-proxy-*.svg` | Монолит `assets/icons/win/tenga-proxy-*.ico` |

Логотип привязан к интерфейсу, а не к проверке ОС: виджеты не читают `IS_WINDOWS`.
Поэтому `gui.py --ui qt` на Linux показывает монолит, это режим для разработки.

Голубя на Windows и монолита в GTK быть не должно. В deb-пакет каталог
`assets/icons/win` не попадает.

## Намеренное отличие: навигация

| | Linux (GTK) | Windows (Qt) |
| --- | --- | --- |
| Устройство окна | Вкладки «Серверы», «Подписки», «Диагностика» | Один экран |
| Список подписок | Вкладка | Страница настроек |
| Состояние соединения, маршруты, журнал | Вкладка | Окна «Диагностика» и «Журнал» |
| Поиск | Кнопка в заголовке, ищет на текущей вкладке | Поле над списком |
| «Добавить» | Значок в заголовке | Кнопка над списком |
| «Переключить на выбранный» | На карточке, видна с любой вкладки | Под списком |
| «Обновить подписку» | В строке на вкладке «Подписки» | В меню строки группы |
| «Журнал…» в главном меню | Нет, журнал на вкладке | Есть |

Отличается только то, где находится элемент. Подпись, условие показа и действие совпадают.

## Что определяет платформа

Это не отличия дизайна, а свойства тулкита и ОС. Они остаются разными:

- рамка окна, системный шрифт, вид стандартных элементов, светлая и тёмная тема;
- механика трея (StatusNotifierItem на Linux, `QSystemTrayIcon` на Windows);
- названия системных механизмов: тексты собраны в `src/ui/logic/platform_texts.py`
  (NetworkManager и VPN Windows, deb-пакет и установщик);
- установка, обновление и служба Windows.

Своей темы нет: цвета берутся из системной палитры. Исключения — цвета состояний
соединения и сам логотип.

## Где живёт общее

Общее описывается один раз, в коде без тулкита, и проверяется обычным pytest:

| Что | Где |
| --- | --- |
| Состояния соединения, заголовки, кнопки, метрики | `src/ui/logic/status.py` |
| Строки серверов и групп, задержка, пустой список, подсказка поиска | `src/ui/logic/profiles_view.py` |
| Меню «Добавить» и главное меню | `src/ui/logic/menus.py` |
| Подписки | `src/ui/logic/subscriptions_view.py` |
| Диагностика | `src/ui/logic/monitoring_view.py` |
| Состав меню трея | `src/ui/tray/menu.py` |
| Поведение и тосты | `src/ui/controller.py` |

Правило: текст, который видит пользователь, и условие его показа сначала идут сюда.
Виджет только раскладывает готовые данные. Подпись прямо в виджете допустима, только
если она не зависит от состояния; такие подписи совпадают по таблицам этого документа.

Имена действий одни и те же в обоих тулкитах (`toggle-connection`, `add-profile`…).

## Главное окно

Порядок сверху вниз:

1. **Заголовок окна.**
2. **Карточка статуса:** логотип-кнопка, имя сервера, состояние, режим, метрики, строка
   проверки соединения.
3. **Баннер** «Изменения применятся после переподключения» с кнопкой «Переподключить».
4. **Содержимое:** на Linux вкладки, на Windows список серверов с нижней строкой.

Карточка видна всегда, на Linux она стоит над вкладками. Выбор серверов остаётся основным
содержимым окна. На низком окне карточка становится компактной, логотип уменьшается, но не
исчезает. На Linux, где под карточкой ещё и вкладки, она должна оставаться невысокой:
логотип сбоку, 72 пикселя и 48 при высоте окна до 560 (предложено).

### Логотип как кнопка

- Настоящая кнопка: фокус с клавиатуры, реакция на наведение и нажатие, доступное имя
  совпадает с `button_label`, подсказка объясняет действие.
- Вызывает `toggle-connection`: один клик — одно действие.
- Во время подключения и отключения кнопка заблокирована: контроллер не умеет прерывать
  начатую операцию, поэтому кнопки «Отменить» нет.
- Логотип сохраняет пропорции, постоянной пульсации нет.

## Состояния

Заголовок, кнопка и доступность берутся из `StatusView`.

| Состояние | Заголовок | Подпись | Действие | Логотип |
| --- | --- | --- | --- | --- |
| Нет серверов | «Добавьте сервер или подписку» | — | недоступно | приглушённый |
| Отключено | «Отключено» | выбранный сервер | «Подключить» | приглушённый |
| Подключение | «Подключение…» | целевой сервер | заблокировано | индикатор ожидания |
| Отключение | «Отключение…» | активный сервер | заблокировано | индикатор ожидания |
| Подключено | «Подключено» | активный сервер | «Отключить» | цветной |
| Ошибка | «Ошибка» | выбранный сервер, причина в строке проверки | «Повторить» | предупреждение |

Состояние никогда не передаётся только цветом: его всегда называет заголовок.
Способ показа задаёт реализация: монолит перекрашивается в SVG, для голубя цветной и
обесцвеченный варианты плюс спиннер или значок предупреждения поверх (предложено).

### Честные формулировки

«Подключено» значит только, что сессия запущена. Работает ли соединение, говорит
отдельная строка из `health_text()`:

- «Проверка соединения ещё не выполнена»;
- «Прокси запущен, соединение не прошло проверку»;
- «Последняя проверка соединения: …».

Не писать «Защищено» и «Интернет работает». Для системного прокси не обещать охват всего
трафика.

### Метрики и режим

- Метрики идут отдельными значениями из `metric_items`: «Задержка», «↓ Получено»,
  «↑ Отправлено». Неизвестное значение не показывается.
- Единица задержки — «мс». Отсутствие замера — «—», это не отказ.
- Режим называется «Системный прокси» или «TUN» (`mode_text`).
- На Qt метрики стоят столбиками. На Linux режим и метрики идут одной строкой у левого края
  через «·» (`summary_line`), на узком окне строка переносится между значениями: карточка над
  вкладками должна оставаться невысокой, а значения не должны расходиться по широкому окну.

## Выбранный и активный сервер

- Одинарный клик только выделяет строку и не трогает соединение.
- Enter и двойной клик подключают сервер.
- У активного сервера метка «Подключён» независимо от выделения.
- Пока сессия запущена, карточка показывает активный сервер.
- Если выделен другой сервер, появляется кнопка «Переключить на выбранный», а её подсказка
  называет цель. До нажатия текущая сессия не меняется.

## Словарь

| Слово | Значение | Не использовать |
| --- | --- | --- |
| Сервер | Запись с настройками подключения, то, что выбирают и подключают | «Профиль» |
| Адрес | Хост и порт сервера, колонка в списке | «Сервер» в этом значении |
| Подписка | Источник серверов по ссылке | «Ссылки» |
| Группа | Набор серверов | |
| Набор маршрутов | Правила из ссылки `veblock://routing/…`, это не сервер | «Профиль» |
| Задержка | Измеренное время отклика | «Пинг» в новых текстах |
| Диагностика | Состояние соединения, маршрутов и журнал | «Мониторинг» как название экрана |
| Мониторинг | Только фоновая проверка соединения и её настройки | |

Словарь относится к тому, что пользователь видит в окне, трее и уведомлениях. Код и форматы
данных не меняются: `ProfileEntry`, `src/db/profiles.py`, `core/profiles/`, `add-profile`
и другие имена остаются, потому что их смена требует миграции. Команды CLI тоже остаются.

Название приложения — Veblock (`src.__app_name__`). Обращение безличное, многоточие
ставится у пунктов, открывающих форму.

## Меню и списки

**Добавить:** «Сервер по ссылке…», «Сервер из буфера обмена», «Подписка…», «Группа…».

**Главное меню:** «Обновить подписки», «Проверить задержку», «Настройки», «Журнал…» (только
Windows), «Сочетания клавиш», «О программе», «Выход».

**Строка сервера:** «Подключить», «VPN и маршруты…», «Тест задержки»; «Редактировать»,
«Удалить».

**Строка группы:** «Свернуть/Развернуть группу», «Обновить подписку» (только Windows и только
у подписки), «Тест задержки», «Оставить рабочие…»; «Редактировать», «Удалить».

**Колонки:** «Имя», «Тип», «Адрес», «Задержка». При обновлении задержки выделение и позиция
чтения не меняются. Строка группы занимает всю ширину: название, число серверов, ход
проверки, сведения подписки.

**Строка подписки:** «Пустой список серверов» и «Обновлено через запасной адрес»
показываются одинаково в GTK и Qt. Тексты — в `src/ui/logic/subscriptions_view.py`.

**Поиск:** подсказка «Имя, тип, адрес или группа».

**Пустой список:** «Серверов пока нет», «Добавьте сервер по ссылке или подключите подписку.»

**Настройки:** «Общие», «Мониторинг», «DNS», «Обход блокировок», «Подписки», «О программе».

**Трей:** состав задаёт `build_menu()` в `src/ui/tray/menu.py`, он уже общий: «Серверы»,
«Добавить сервер…», «(нет серверов)».

## Сочетания клавиш

Таблицы `_ACCELS` (GTK) и `SHORTCUTS` (Qt) совпадают:

| Клавиши | Действие |
| --- | --- |
| Ctrl+Return | Подключить или отключить |
| Ctrl+T | Проверить задержку |
| Ctrl+N | Добавить сервер |
| Ctrl+Shift+N | Добавить подписку |
| F5 | Обновить подписки |
| Ctrl+F | Поиск |
| Ctrl+, | Настройки |
| Ctrl+W | Скрыть окно |
| Ctrl+Q | Выход |

## Доступность и проверка

В обоих интерфейсах: управление с клавиатуры, видимый фокус, обе темы, масштаб 100–200%,
длинные имена сокращаются многоточием с полным текстом в подсказке.

Перед выпуском изменения интерфейса проверить: пустое хранилище; выбранный и активный
сервер разные; подключение; отказ; проверка не завершена; низкое окно.

## Расхождения

Что отличается от описанного выше после выполнения порядка работ на базе `7e6e23a`.

| Что | Сейчас | Нужно |
| --- | --- | --- |
| Поиск без результатов | GTK «Серверов пока нет», Qt «Ничего не найдено. Измените запрос.» | Как в Qt, текст в `profiles_view.py` |
| Первая строка диагностики до проверки | Qt подменяет её на «Проверка ещё не выполнена», GTK показывает значение `monitoring_view` | Общий текст в `monitoring_view.py` |
| Вывод CLI | Говорит «профиль» (19 строк `cli.py`) | Вне словаря, пока команды не переименованы |
| Снимки `assets/screen-*.png` | Старый интерфейс | Снять заново |
| Узкое окно на Linux | Страница диагностики требует 450 пикселей при минимуме окна 360, содержимое обрезается | Минимум страницы не больше минимума окна |

## Выполнено

1. Голубь в Qt «О программе» заменён на монолит.
2. Термин «Сервер» в интерфейсе, тестах и пользовательской документации. `docs/*/api.md` и
   `docs/*/development.md` описывают код и говорят о `ProfileEntry` и профилях намеренно.
3. Тексты, единицы и меню выровнены, общее вынесено в `src/ui/logic/`.
4. GTK-карточка: логотип-кнопка с голубем вместо отдельной кнопки, `metric_items`, общая
   обработка ошибки и пустого хранилища.

## Вне этого документа

Отмена начатого подключения, избранное и новые поля в схеме серверов: это изменения общего
кода, они обсуждаются отдельно.
