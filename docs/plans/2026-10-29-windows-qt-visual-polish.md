# Windows Qt: исправление компоновки после 0.21.0

База: `26c9c27` (`v0.21.0`).

## Область изменений

Изменения только в `src/ui/qt/`, Qt-тестах и этом документе.
GTK, общий контроллер, `src/ui/logic/`, ядро, системные реализации,
служба, зависимости и Linux-сборка не изменяются.
Экспериментальный запуск Qt через `--ui qt` также использует эти виджеты;
штатный интерфейс Linux остаётся на GTK.

## Реализовано

- Начальная геометрия Qt 1180×760, минимум 900×540, отдельно от GTK.
- Компактная кнопка подключения с оформлением suggested/destructive,
  второстепенный переключатель мониторинга, текстовый fallback меню.
- Имя профиля сокращается многоточием с полным текстом в подсказке.
- Заданы начальные ширины типа, адреса и задержки; ручное изменение
  сохраняется в течение жизни окна. Для адресов добавлены подсказки.
- Группа занимает всю ширину строки: название, количество профилей,
  прогресс проверки и сведения подписки. Колонки сервера и пинга
  содержат только данные профилей.
- Убраны полосатые строки, увеличены отступы, выделяется вся строка,
  задержка выровнена вправо. Активный профиль остаётся полужирным.
- Добавлены объяснения пустого списка и отсутствия результатов поиска.
- В мониторинге оставлены показатели состояния и действия.
- Журнал открывается отдельным немодальным окном из панели и меню.
  Добавлен переключатель переноса строк, сохранение позиции чтения,
  остановка таймера при скрытии и сообщение об ошибке чтения.
  Для текста выбирается Cascadia Mono или Consolas, если установлен;
  иначе используется системный моноширинный шрифт.
  Маскирование, экспорт и подтверждение очистки используют прежний код.
- Общий каркас Qt-форм получил отступы, высоты элементов, перенос
  длинных строк формы и размещение в рабочей области экрана.
  Настройкам задан минимальный размер. Валидация и автосохранение прежние.

## Проверки

Среда: Windows, CPython 3.11.4, PySide6 6.12.0.

- Нативный Qt-набор Windows: 147 passed.
- Обязательный Windows unit-набор из AGENTS.md: 182 passed, 14 skipped.
- Компоновка: светлая/тёмная темы, 900×600, 1180×760, 1920×1080;
  отдельные процессы с QT_SCALE_FACTOR=1, 1.25, 1.5, 2 — 24 passed.
  Это моделирование масштаба Qt, а не проверка переноса окна между мониторами.
- Ruff: весь репозиторий, check и format --check прошли.
- git diff --check прошёл.
- PyInstaller: чистая Windows-сборка в `dist/windows-review/tenga-proxy/`.
  Frozen smoke: процесс жив через 8 секунд, выбран Qt, QSS включён,
  GTK не включён, traceback в журнале отсутствует. Запуск с отдельными
  пустыми настройками, без запуска прокси и установки службы.
- Снимки нативного Qt созданы на синтетических профилях вне репозитория.
  Offscreen-снимки в этой среде не годятся для визуального контроля шрифтов.
  Просмотрены главное окно, настройки, журнал, состояния подключения и ошибки.

## Ограничения проверки

Первый локальный frozen-запуск выявил загрязнение PATH окружением Codex:
PyInstaller включил `icuuc.dll` из bundled Poppler, несовместимую с Qt.
Диагностический запуск с системной ICU подтвердил причину. Для итоговой
проверочной сборки PATH ограничен `.venv/Scripts`, Windows и Git;
исходный spec не изменён. Это не исправление логики приложения.

Linux GTK, D-Bus, TUN и deb здесь не проверяются. Полный сбор pytest на
Windows останавливается на Linux-модулях трея без gi; целевые наборы
запускаются отдельно. Интеграционные тесты установленной службы не запускались.
Нативная проверка проведена на доступной Windows; отдельная Windows 10
и физическая смена DPI/мониторов не проверялись.
Inno Setup в среде отсутствует: установщик не собран.
Версия проекта не меняется, релиз не публикуется.
