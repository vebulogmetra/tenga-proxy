# VPN

Tenga Proxy предоставляет интеграцию с VPN-соединениями для комплексного управления сетевым трафиком.

## Основные возможности

- **Автоматическое подключение VPN** перед запуском прокси
- **Маршрутизация трафика через VPN** для определенных доменов/IP
- **Интеграция с NetworkManager** для управления VPN-соединениями
- **Автоматическое отключение VPN** после остановки прокси

## Настройка VPN-интеграции

### В профиле

Каждый профиль может иметь индивидуальные настройки VPN:

- **Включение/отключение интеграции** - глобальное включение/отключение VPN-интеграции для профиля
- **Название соединения** - имя VPN-соединения в NetworkManager
- **Автоподключение** - автоматическое подключение VPN перед запуском прокси
- **Интерфейс** - указание конкретного интерфейса для прямого трафика

### В маршрутизации

VPN-интеграция работает в связке с системой маршрутизации:

- **Список "over VPN"** - домены и IP, трафик к которым направляется через VPN
- **Приоритет маршрутов** - правильная последовательность обработки правил
- **Интерфейсные настройки** - направление трафика через нужный интерфейс

## Поддерживаемые типы VPN

Tenga Proxy поддерживает VPN-соединения, управляемые через NetworkManager:

- **OpenVPN** - через .ovpn файлы
- **WireGuard** - через конфигурационные файлы
- **IPsec/L2TP** - корпоративные VPN
- **PPTP** - устаревшие, но все еще используемые
- **Системные VPN** - любые VPN, настроенные в NetworkManager

## Автоматическое подключение

### При запуске прокси

Если включена опция автоподключения:

1. Проверяется статус VPN-соединения
2. Если соединение не активно, выполняется подключение
3. После успешного подключения запускается прокси
4. При остановке прокси может выполняться отключение VPN

### Проверка статуса

Система проверяет статус VPN-соединения:

- **Активность соединения** - проверка через NetworkManager
- **Интерфейс соединения** - определение используемого интерфейса
- **DNS-сервера VPN** - получение DNS-серверов из настроек VPN

## Маршрутизация через VPN

### Правила маршрутизации

Трафик может быть направлен через VPN на основе правил:

- **Доменные имена** - направление трафика к определенным доменам через VPN
- **IP-адреса** - направление трафика к определенным IP-адресам через VPN
- **Геолокация** - потенциальная возможность направления трафика по географическому признаку

### DNS-интеграция

При использовании VPN для определенных доменов:

- **VPN DNS-сервера** - использование DNS-серверов из VPN-соединения
- **Разрешение имен** - правильное направление DNS-запросов
- **Избегание утечек** - предотвращение утечек DNS-запросов

## Настройка в GUI

### В окне профиля

В настройках профиля можно:

- Включить/отключить VPN-интеграцию
- Выбрать VPN-соединение из списка
- Включить автоподключение
- Указать интерфейс для прямого трафика

### В настройках маршрутизации

В настройках маршрутизации:

- Настройка списков "over VPN"
- Определение приоритета правил
- Тестирование маршрутов
