# Профили

Управление профилями в Tenga Proxy позволяет эффективно организовать и использовать различные настройки прокси-соединений.

## Основные понятия

**Профиль** - это сохраненная конфигурация подключения к прокси-серверу, содержащая:

- Параметры подключения (сервер, порт, учетные данные)
- Настройки транспорта
- Параметры безопасности
- Имя и описание

**Группа** - это коллекция профилей, объединенных по какому-либо признаку (например, по провайдеру или типу использования).

## Создание профилей

### Из share-ссылки

Профили можно создавать из share-ссылок различных протоколов:

```bash
# CLI
python cli.py add "vless://..."

# GUI
# Используйте кнопку "Добавить" в главном окне
```

### Из подписки

Профили могут автоматически создаваться из подписок:

- Подписки могут быть в формате base64, plain text или готовым конфигом xray (JSON)
- Профили группируются в специальные группы подписок
- Подписки обновляются только вручную: кнопкой в строке подписки или `F5`

#### Что происходит при обновлении

- Профиль, который остался в ответе провайдера (то же имя, тип, сервер и порт),
  обновляется на месте: его замер задержки, персональные настройки
  маршрутизации и VPN сохраняются, подключённый профиль остаётся подключённым.
  Пропавшие из ответа профили удаляются. Пустой ответ ничего не трогает.
- Если подключён профиль в режиме системного прокси, подписка загружается
  сначала через него, а при неудаче — напрямую. В режиме TUN запросы
  приложения и так идут через туннель. Запрос через локальный прокси
  подчиняется правилам маршрутизации приложения.
- Название подписки можно не вводить: подставится хост адреса, а провайдер
  сможет заменить его своим (`profile-title`). Введённое вручную название
  провайдер не меняет.

#### Сведения от провайдера

Из заголовков ответа и строк `#ключ: значение` в теле читаются:

| Ключ | Что показывается |
|---|---|
| `subscription-userinfo` | израсходованный трафик, лимит и срок действия |
| `announce` | объявление провайдера (кнопка с «i» в строке подписки) |
| `support-url` | пункт меню «Поддержка» (http, https или tg) |
| `profile-web-page-url` | пункт меню «Страница подписки» (только https) |
| `profile-title` | название подписки, если его не задал пользователь |
| `new-url`, `fallback-url` | предложение сменить адрес — только с подтверждением |

Значение может быть закодировано с префиксом `base64:`. Ключи, которыми
провайдер управлял бы настройками клиента, не распознаются.

#### Настройки → Подписки

- **User-Agent.** По умолчанию `v2rayNG/1.8.23` для совместимости с провайдерами.
- **Отправлять данные устройства.** Выключено. При включении провайдеру уходят
  случайный идентификатор установки (`x-hwid`), название и версия системы,
  модель компьютера. Нужны провайдерам, которые считают лимит устройств: без
  них такой провайдер отвечает 403.

## Управление профилями

### Просмотр профилей

В GUI профили отображаются в виде дерева с группами:

- Группы отображаются как папки
- Профили внутри групп
- Информация о типе, адресе и задержке

### Редактирование профилей

Профили можно редактировать:

- Изменение имени профиля
- Настройка параметров подключения
- Изменение настроек транспорта
- Настройка VPN и маршрутизации

### Удаление профилей

Профили можно удалять:

- Удаление отдельных профилей
- Удаление целых групп
- Удаление профилей из подписок

## Группы профилей

### Обычные группы

Обычные группы позволяют:

- Организовывать профили по категориям
- Быстро переключаться между группами
- Управлять профилями в группе

### Группы подписок

Группы, созданные из подписок:

- Автоматически обновляются
- Синхронизируются с источником
- Не могут быть переименованы вручную

## Тестирование задержки

Для каждого профиля можно протестировать задержку:

- Измерение времени отклика сервера
- Сравнение производительности профилей
- Автоматическое обновление результатов

## Настройки профиля

Каждый профиль может иметь индивидуальные настройки:

- **VPN-интеграция** - настройка подключения к VPN
- **Маршрутизация** - правила направления трафика
- **Параметры безопасности** - настройки TLS и шифрования
- **Дополнительные параметры** - кастомные настройки
