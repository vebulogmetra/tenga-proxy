# Hiddify: изменения между 2.0.5 и 5.5.5

Дата сравнения: 9 ноября 2026 года. На эту дату GitHub помечает 5.5.5
как последний стабильный релиз; он опубликован 4 ноября 2026 года.
Это сводка пользовательских изменений, без повторов и служебных коммитов,
а не полный построчный список изменений исходников.

## Исходная версия

Релиз 2.0.5 существует, хотя отдельная запись о нём в HISTORY.md отсутствует.
Xray, расширенный редактор конфигураций, Split HTTP, дополнительные режимы WARP
и IPv4/IPv6 для WireGuard уже описаны в релизе 2.0.5 и не считаются новинками.

Источник: [релиз 2.0.5](https://github.com/hiddify/hiddify-app/releases/tag/v2.0.5).

## Основные возможности актуального релиза

| Область | Изменения |
| --- | --- |
| Обход блокировок | DNS-туннели DNSTT, MasterDNS, Soar; Psiphon, GooseRelay, XHTTP, mKCP, XDRIVE, FinalMask, Mirage, AmneziaWG, VLESS Encryption, Mieru, Sudoku |
| WARP | WireGuard, AmneziaWG, MASQUE; автоматический выбор самого быстрого варианта, сканер адресов, шум под DNS, QUIC и SIP |
| Цепочки | Extra Security и Unblocker: WARP или Psiphon для дополнительной защиты либо доступа к заблокированному прокси |
| Подписки | Выбор запускаемых серверов, сохранение лучших, проверка скорости загрузки и отдачи |
| Интерфейс | Новый главный экран, живые статусы серверов, задержка в виде уровня сигнала, этапы подключения |
| Диагностика | Причина отказа в сведениях о сервере |
| Безопасность | Шифрование канала приложения с ядром, удаление приватных данных из отчётов о сбоях |
| Обновления | Встроенное обновление Android, Windows, Linux и macOS |
| Платформы | VPN через системное расширение macOS, сборка Mac App Store; импорт подписки на Android TV с телефона через QR-код |

Эти возможности заявлены в [релизе 5.5.5](https://github.com/hiddify/hiddify-app/releases/tag/v5.5.5).
Его описание использует общее название обновления «v5.5.0».
Названия XHTTP и Split HTTP связаны: список не означает, что вся эта технология
впервые появилась после 2.0.5. Наличие возможностей не гарантирует обход блокировок
в конкретной сети; часть требует совместимого сервера.

## Промежуточные изменения и исправления

- **2.1–2.5:** исправления миграции базы, проверок задержки, VPN-службы Android
  и генерации WARP; действие при закрытии окна, доработки трея и переводов.
- **4.x:** быстрые настройки, TLS-фрагментация, настройка балансировщика,
  входящие подключения TPROXY/REDIRECT/DIRECT, улучшения переподключения и сведений об IP.
- **5.x:** исправления перезапуска ядра и восстановления списка серверов;
  сохранение результатов тестов и сортировка по скорости.
- **5.5.5:** единое окно экспорта подписки и конфигурации, управление LAN-раздачей,
  исправления Fake DNS, WARP при смене сети и ошибки Windows-установщика 740.
- **Изменение настройки в 5.5.5:** «Использовать xray-core, когда возможно»
  отключено и скрыто; сохранённое значение игнорируется. Это не означает
  удаления всей поддержки Xray.

Источник: [HISTORY.md на теге 5.5.5](https://github.com/hiddify/hiddify-app/blob/v5.5.5/HISTORY.md).
Промежуточные теги могли быть предварительными версиями; перечисление их изменений
не является рекомендацией устанавливать эти сборки.

## Границы сравнения

Сводка основана на официальных описаниях релизов и журнале изменений.
Сравнительные испытания скорости, стабильности и совместимости не выполнялись.
Поддержка функции может отличаться между ОС и вариантами сборки.

См. также [сравнение Hiddify 5.5.5 с Veblock](hiddify-5.5.5-vs-veblock.md).
