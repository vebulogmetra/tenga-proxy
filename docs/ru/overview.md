# Обзор проекта

Tenga Proxy - это современный клиент прокси для Linux с backend [xray-core](https://github.com/XTLS/Xray-core), который предоставляет удобный интерфейс для работы с различными протоколами прокси.

## Назначение проекта

Проект создан для:

- **Упрощения работы с прокси-серверами** - предоставляет удобный интерфейс для различных протоколов
- **Обеспечения анонимности** - позволяет скрывать реальный IP-адрес
- **Обхода блокировок** - обеспечивает доступ к заблокированным ресурсам
- **Управления трафиком** - гибкая маршрутизация сетевого трафика
- **Интеграции с VPN** - комплексное управление сетевыми соединениями

## Архитектура

### Общая архитектура

Tenga Proxy использует архитектуру с разделением на:

- **Интерфейс** - CLI и GUI для взаимодействия с пользователем
- **Ядро приложения** - логика управления и координация
- **Модули форматирования** - парсинг и форматирование ссылок
- **Менеджер данных** - хранение и управление профилями
- **Backend** - xray-core для обработки сетевого трафика

### Основные компоненты

- **AppContext** - центральный контекст приложения
- **ProfileManager** - управление профилями и группами
- **XrayManager** - управление xray-core
- **ProxyState** - отслеживание состояния прокси
- **ConnectionMonitor** - мониторинг соединений

## Функциональные возможности

### Поддержка протоколов

- **VLESS** - современный протокол с поддержкой Reality и XTLS
- **Trojan** - высокобезопасный протокол
- **VMess** - совместимость с V2Ray
- **Shadowsocks** - классический протокол с современными методами
- **SOCKS** - стандартные протоколы SOCKS4/4a/5
- **HTTP/HTTPS** - HTTP-прокси

### Управление профилями

- **Создание профилей** из share-ссылок
- **Группировка профилей** по категориям
- **Импорт подписок** в различных форматах
- **Тестирование задержки** до серверов
- **Редактирование параметров** подключения

### Маршрутизация трафика

- **Гибкие правила маршрутизации** для разных типов трафика
- **Интеграция с VPN** для комплексного управления
- **Настройка DNS** для разных маршрутов
- **Исключение локальных сетей** из прокси

### Системная интеграция

- **Системный трей** для быстрого доступа
- **Автоматическая настройка системного прокси** для GNOME/KDE
- **Уведомления** о состоянии соединений
- **Мониторинг** через Stats API
