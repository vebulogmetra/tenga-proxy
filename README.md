# Veblock

Veblock — прокси-клиент для Linux и Windows
на базе [xray-core](https://github.com/XTLS/Xray-core).

[Скачать](https://github.com/vebulogmetra/tenga-proxy/releases) ·
[Установка](docs/ru/installation.md) · [Документация](docs/ru/overview.md)

</div>

![Главное окно](assets/screen-profiles.png)

## Что это

Приложение для подключения к прокси-серверам. Понимает ссылки вида
`vless://`, `trojan://`, `vmess://`, `ss://` и подписки, умеет пускать через
прокси весь трафик системы или только выбранные сайты.

Для подключения нужен свой сервер или подписка от провайдера прокси.

## Возможности

- **Протоколы:** VLESS (включая Reality и XTLS), Trojan, VMess,
  Shadowsocks (включая методы 2022), Hysteria2, SOCKS, HTTP
- **Транспорты и маскировка** — XHTTP, WebSocket, gRPC, HTTPUpgrade,
  настраиваемая фрагментация TLS
- **Подписки** — импорт и обновление списков серверов, повторный импорт
  в существующую группу, ссылки `veblock://`
- **Два режима работы** — TUN (весь трафик системы, как у VPN) или
  системный прокси (GNOME/KDE и Windows настраиваются автоматически)
- **Гибкая маршрутизация** — отдельные правила для доменов и подсетей:
  напрямую, через прокси или через VPN
- **Автопереключение** — переход на другой сервер той же группы после
  заданного числа неудачных проверок
- **Выбор DNS** — Google, Cloudflare, AdGuard или свой сервер; запросы
  можно пускать через прокси
- **Диагностика** — состояние соединения, VPN и активных правил
- **Диагностика сети** — проверка вручную: белые списки, доступ к Telegram, Instagram и
  YouTube, DNS; итог можно скопировать, отчёт без адресов — сохранить в файл

## Установка

### Linux

Скачайте `tenga-proxy_<версия>_amd64.deb` со страницы
[Releases](https://github.com/vebulogmetra/tenga-proxy/releases) и установите:

```bash
sudo apt install ./tenga-proxy_<версия>_amd64.deb
```

### Windows

Скачайте `veblock-<версия>-windows-x64-setup.exe` со страницы
[Releases](https://github.com/vebulogmetra/tenga-proxy/releases) и запустите.
Нужны Windows 10 или 11 (x64) и права администратора на время установки.
Qt, xray-core и драйвер wintun входят в установщик.

## Как пользоваться

### Добавить сервер

Нажмите **Добавить… → Сервер по ссылке…** над списком и вставьте ссылку
подключения. Приложение разберёт её само: имя, адрес и протокол заполнятся
автоматически.

Если у вас есть ссылка на подписку, выберите **Добавить… → Подписка…** —
список серверов загрузится целиком. Подписки собраны в **Настройки →
Подписки**: там их можно обновить, изменить или удалить.

### Подключиться

Выберите сервер в списке и нажмите на логотип в панели слева. Двойной клик по
строке подключает сразу. Пока соединение работает, выделение другой строки его
не меняет: для смены сервера нажмите **Переключить на выбранный** под списком.

Задержка до сервера видна справа в строке. Чтобы измерить её у всех сразу,
нажмите **Проверить задержку** или `Ctrl+T`.

Пинг помогает сравнить задержку, но не измеряет скорость загрузки и не подтверждает
работу всех правил, DNS и TUN. Состояние текущего подключения показывает диагностика.

В **Настройках → Мониторинг → Автопереключение** можно включить переход
на другой сервер группы при отказе текущего и задать порог неудачных проверок.

### Проверить состояние

Кнопка **Диагностика** под списком показывает, работает ли прокси, поднят ли
VPN, какие правила маршрутизации сейчас действуют, и журнал.

Кнопка **Диагностика сети…** там же, одноимённый пункт главного меню или `Ctrl+D` открывают
проверку сети. Она запускается только вручную и идёт до 3 минут, до 8 МиБ данных плюс
служебный трафик. Запросы идут напрямую, настройки не меняются. Если включена блокировка
трафика, прямые запросы не выполняются, и окно это объясняет.

## Сочетания клавиш

| Сочетание | Действие |
|-----------|----------|
| `Ctrl+Return` | Подключить или отключить |
| `Ctrl+T` | Проверить задержку |
| `Ctrl+D` | Диагностика сети |
| `Ctrl+N` | Добавить сервер |
| `Ctrl+Shift+N` | Добавить подписку |
| `F5` | Обновить подписки |
| `Ctrl+F` | Поиск по списку |
| `Ctrl+,` | Настройки |
| `Ctrl+W` | Скрыть окно |
| `Ctrl+Q` | Выход |

## Режимы работы

**TUN** (по умолчанию) — приложение поднимает виртуальный сетевой интерфейс
и направляет системный трафик по настроенным правилам, включая трафик программ,
которые не умеют работать с прокси. Правила могут отправлять отдельные адреса напрямую.

**Системный прокси** — приложение поднимает локальный SOCKS и HTTP прокси и
прописывает его в настройки рабочего стола. Трафик пойдёт только у программ,
которые эти настройки читают.

Режим переключается в **Настройках → Общие**.

## Командная строка

У проекта есть и консольный интерфейс — он пригодится на сервере без
графики или в скриптах. Работает при запуске из исходников:

```bash
# Добавить сервер и посмотреть список
uv run python cli.py add "vless://..."
uv run python cli.py ls

# Запустить в режиме системного прокси по номеру из списка
uv run python cli.py run 1 --mode system-proxy

# Проверить, что трафик идёт через прокси
curl --proxy socks5h://127.0.0.1:2080 https://ifconfig.me

# Справка
uv run python cli.py --help
```
